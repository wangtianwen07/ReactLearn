# ReactLearn

An interactive React learning app covering the core concepts through live, editable examples.

## Topics Covered

| # | Lesson | Concepts |
|---|--------|----------|
| 1 | **Components** | Functional components, JSX |
| 2 | **Props** | Passing data, destructuring |
| 3 | **useState** | Counter, toggle, controlled input |
| 4 | **useEffect** | Timers, event listeners, data fetching |
| 5 | **Lists & Keys** | `.map()`, unique keys, dynamic lists |
| 6 | **useContext** | Context creation, Provider, consumer |

## Getting Started

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Tech Stack

- [React 19](https://react.dev/)
- [Vite](https://vite.dev/)
