# 6 个月路线总表（24 周）：React SPA（Vite）主线 + Next.js 辅线 + RBAC + 微前端

> 说明：详细内容按月份见 `01~06` 六篇文档；本文件提供“一页纸总览”，便于你按周推进。

- 节奏：每周 10 小时（3h 概念 + 5h 编码 + 2h 复盘）
- 核心原则：**每周必须有可演示产出**（页面/流程/组件/测试/文档任一）

---

## 里程碑（你要始终盯住）

- M1：中后台静态原型（布局+列表+表单+详情）
- M2：单体 SPA 可用（登录+路由+CRUD+请求层+状态分层+表单）
- M3：工程化可协作（规范+测试+CI+可观测性占位）
- M4：RBAC 三层权限闭环（菜单/按钮/数据）+ IAM 域可管理
- M5：微前端按业务域拆分（qiankun）+ 子应用独立发布说明
- M6：Next.js 辅线（帮助中心）+ Capstone 交付包
