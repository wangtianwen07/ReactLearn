# 01 第 1 月：Web/浏览器 + TypeScript 基础（并做出静态原型）

> 本月定位：补齐“浏览器运行时 + TS 工程语言”两块短板，同时做出一个中后台静态原型（不强依赖后端），为第 2 月 React SPA 主线铺路。

- 时间预算：4 周 × 10h/周
- 本月产出物（必须）：
  1. 中后台静态原型：布局 + 列表 + 表单搜索 + 详情页（静态数据/Mock）
  2. 个人 TS 类型建模笔记（以“业务可读”为导向）
  3. DevTools 调试笔记：Network/Performance/Memory 至少各 1 个案例

---

## 1.1 本月你要掌握的“够用知识”范围

### 浏览器与 Web（够用即可）

- DOM 事件：捕获/冒泡/事件委托（中后台表格操作很常用）
- 事件循环：宏任务/微任务（理解 effect、Promise、setTimeout 的顺序）
- 渲染性能：重排/重绘/合成（理解为什么某些 CSS/JS 会造成卡顿）
- 网络与安全：
  - CORS（常见跨域排错）
  - Cookie/SameSite（SSO、网关常遇到）
  - HTTP 缓存（ETag/Cache-Control 的概念口径）

### TypeScript（企业级最常用部分）

- 类型建模：
  - `PageResponse<T>`、`ApiResponse<T>`、`Option<T>`、`Record<string, T>`
  - 联合类型表示状态机（loading/success/error）
- 约束边界：
  - `unknown` + 类型守卫（不要滥用 `any`）
  - 运行时校验（Zod）与类型一致性（第 2 月会落地）
- 工程化：strict 模式的价值（减少线上 NPE 类问题）

## 1.2 每周安排（10h/周）

> 模板：3h 概念 + 5h 编码 + 2h 复盘沉淀。

### Week 1：浏览器与调试入门（把“定位问题”的能力建起来）

**学习重点（3h）：**

- DOM/事件模型
- DevTools：Network（请求）、Elements（样式）、Console（错误）

**编码练习（5h）：**

- 用纯 HTML/CSS/TS（不必上 React）做：
  - 一个页面布局：Header + Sidebar + Content
  - 一个表格页面：静态数据 + 简单筛选（前端过滤）

**复盘（2h）：**

- 写一篇“我如何在 DevTools 里定位接口问题”的笔记（截图 + 结论）

**验收：**

- 能用事件委托实现表格行操作（比如点击“查看详情”）
- 能解释“为什么我点一次会触发两次事件（冒泡/绑定位置）”

---

### Week 2：TS 作为工程语言（你写得出来、团队看得懂）

**学习重点（3h）：**

- 泛型/联合/交叉、类型守卫、函数重载（了解即可）

**编码练习（5h）：**

- 抽象一个“业务类型层”（仅 TS 文件即可）：
  - 用户、角色、菜单、工单、看板指标的类型
  - 分页响应、错误码类型、字典选项类型

**复盘（2h）：**

- 总结：哪些地方用了 `any`？为什么？是否可以替换为 `unknown` + 守卫？

**验收：**

- 你能在不看实现的情况下，仅看类型就明白数据结构含义

---

### Week 3：CSS 与中后台布局（能写“够用且稳定”的样式）

**学习重点（3h）：**

- Flex/Grid 常见布局
- overflow、sticky、z-index、滚动容器（表格页经常踩坑）

**编码练习（5h）：**

- 把原型页面补齐：
  - 列表页：顶部筛选表单（多行折叠/展开）
  - 详情页：信息分组、描述列表
  - 统一的“空态/加载态/错误态”占位

**复盘（2h）：**

- 写“滚动容器与 fixed/sticky 冲突”的笔记（你一定会遇到）

**验收：**

- 在 1366×768 下页面不崩；主区域可滚动；侧边栏固定

---

### Week 4：网络与缓存基础 + 原型收口（为第 2 月接接口做准备）

**学习重点（3h）：**

- CORS 常见排错
- 缓存基本口径（no-store/ETag/强缓存）

**编码练习（5h）：**

- 增加“模拟接口层”（可以先写假数据函数）：
  - `listUsers(query): Promise<PageResponse<User>>`
  - `getUserDetail(id): Promise<User>`
- 在原型里把“数据获取”与“UI”分层（不要把数据写死在组件里）

**复盘（2h）：**

- 写一份“第 1 月总结”：
  - 我理解了哪些浏览器概念？
  - 我沉淀了哪些 TS 类型？
  - 原型当前有哪些明显技术债？

**验收：**

- 代码结构已经能看出：数据层/视图层/类型层（哪怕很简陋）
